Bienvenida o bienvenido, en este repositorio se presenta parte de lo entregado para la asigantura Visualización para Ciencia de Datos en Python. Tiene tres ramas, una dedicada
al primer corte, cuyo enfoque fueron los siniestros relacionados con bicicletas en Reino Unido, y otra relacionada al acceso a servicios de saneamiento e higiene, 
y hacinamiento, en Colombia, en 2020 y 2024. Se usaron las siguientes librerías: Numpy, pandas, plotly, streamlit, folium, geopy y ngrok. En la tercera, comparto una investigación personal sobre la generación de datos sintéticos, en la cual, además de las librerías ya mentadas, utilicé las siguientes: distfit, scipy, scikit-learn, svd y statsmodels. En todas las entregas o proyectos se hizo necesario ngrok para poder compartir los tableros sin tener que depender de un servidor local, dado que todos los proyectos fueron colaborativos, excepto el relacionado con la generación de datos sintéticos.
