Este repositorio contiene gráficos realizados en la asignatura de "Presentación de Datos con Python para Ciencia de Datos". Los gráficos sobre los siniestros (accidentes) de bicicletes en Reino Unido, entre 2006 y 2018, correspondieron al trabajo de primer corte. Los mapas presentan algunos problemas relacionados a los permisos para comunicarse con la api. Se generaron en Python y exportaron a HTML.
